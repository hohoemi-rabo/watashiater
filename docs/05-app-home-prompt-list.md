## メモ

### データ層（`lib/use-prompts.ts`）

- prompts と自分の answers を並行取得しクライアント側で結合。ホーム・お題一覧・回答画面で共用
- **「回答済み」の定義＝answers に行が存在する**（チケット06が保存時に行を作る）
- 進捗（answeredCount）は固定10問のみ数える（自由お題は「10このうち」に含めない）
- `useFocusEffect` で画面フォーカス毎に再取得（06で回答して戻ったとき一覧・進捗が追随する）。
  2回目以降はローディング表示を出さない（ちらつき防止）

### 演目札カード（`components/prompt-card.tsx`）

- チケット形は react-native-svg の Path（角丸矩形＋ミシン目位置の上下に半円切り欠き）。
  **切り欠きは透過で背景の空グラデが本当に透ける**。ミシン目は strokeDasharray の点線
- 「済」スタンプ：spot-yellow の円形ボーダー＋Zen Maru の「済」、-8° 傾き（DESIGN §2）
- **影の実装判断**：SVG は非矩形で Android の elevation が使えないため、RN の boxShadow
  （新アーキテクチャで両OS対応）をトークンの影から `hexToRgba` で導出して使用。
  切り欠き部で影が直線のまま通るのは半径9px なので許容（DESIGN §12 判断記録）
- 自由お題枠も同じ札：未作成「＋じぶんでお題をつくる」／作成済みは custom_title＋済

### ホーム

- curtain-red は「つづきをかく」1つだけ（DESIGN §3）。「じぶん史をつくる」は Secondary で
  `answeredCount >= 1` まで disabled（REQUIREMENTS §3.3。遷移先は /story、生成接続は12）
- ギャラリー入り口は deskWood 地のミニプレビュー（DESIGN §7）
