お題に答えて、写真と声で「自分の博物館」を作るアプリ。できあがった博物館は、リンクひとつで家族に見てもらえます。

## 詳細な説明（4000文字以内）

```
ワタシアターは、「自分の博物館（劇場）」を作るアプリです。

白い紙を前に「さあ書いてください」ではありません。「子どものころの話」「夢中になったこと」など、きまったお題が先に用意されています。答えたいお題にだけ、答えたい分だけ。全部答えなくても大丈夫です。

■ お題に答える
「生まれた場所と、子どものころの話」「好きな食べ物」「若い人に言いたいこと」——10のお題と、自分で題を決められる自由枠がひとつ。文字で書いても、声で話して録音してもかまいません。

■ 写真と声をのせる
思い出の写真を添えたり、自分の声でそのときの話を残せます。博物館の「机の上」に写真が並び、写真をタップすると本人の声でその話が流れます。

■ AIが「じぶん史」をつくる
答えた分だけを素材に、AIがひとつの読み物「じぶん史」を紡ぎます。何度でも作り直せて、自分で手直しもできます。

■ 家族に見てもらう
できあがった博物館は、リンクをひとつ送るだけ。見る側はアプリのインストールも登録もいりません。スマホのブラウザで開くだけで、おまごさんにも見てもらえます。見てくれた家族からは「みたよ」が届きます。

■ 大きな文字と、やさしい画面
60代〜80代の方がひとりで使えることを第一に作っています。ボタンは大きく、画面はいつも明るく。昼の劇場（マチネ）のような、これから上映が始まる高揚感のあるデザインです。

■ 安心してお使いいただくために
・写真や声は、期限つきの安全なURLを通してだけ読み出せます
・博物館は、あなたが渡したリンクや招待コードを知っている人だけが見られます
・閲覧ページは検索エンジンに載りません
・アカウントと全データは、アプリ内からいつでも完全に削除できます

あなたの話は、家族にとっての宝物です。ワタシアターで、あなたの博物館を開いてみませんか。
```

## データセーフティ（フォームの回答）

- **収集するデータ**
  - 個人情報 → メールアドレス・名前（Google ログイン）：アプリの機能に必要／共有なし／削除リクエスト可
  - 写真と動画 → 写真：アプリの機能に必要（任意）／共有なし
  - 音声ファイル → 録音した声：アプリの機能に必要（任意）／共有なし
  - アプリのアクティビティ等 → その他のユーザー生成コンテンツ（回答の文章）：アプリの機能に必要／共有なし
- **共有**：第三者への「共有」（Play の定義＝広告・分析等の目的での提供）はなし。保存・処理の委託先は Supabase / Cloudflare / Google Gemini API（プライバシーポリシー記載どおり。委託は Play の定義では「共有」に当たらないサービスプロバイダ扱い）
- **セキュリティ**：転送中のデータは暗号化される＝はい／削除の仕組みがある＝はい（アプリ内＋上記 URL）

## コンテンツレーティングの目安

- 対象は全年齢向け。暴力・性的内容・ギャンブル等なし
- ユーザー生成コンテンツ（UGC）の設問：本アプリの回答・写真・声は**本人が招待した相手だけ**が見られる（不特定多数への公開機能なし）→「クローズドな共有」として回答する

## 内部テストの手順（Play Console）

1. アプリを作成（言語＝日本語、無料）
2. リリース → テスト → 内部テスト → AAB をアップロード（Play App Signing は既定のまま有効化。EAS のキーストアがアップロードキーになる）
3. テスターのメールアドレスを登録 → オプトイン URL を自分の端末で開いてインストール
4. ストアの掲載情報・データセーフティ・コンテンツレーティングは本ファイルのとおり入力
