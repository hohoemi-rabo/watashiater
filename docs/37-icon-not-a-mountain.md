# 37. アプリアイコン：「山に見える」を直す

- ステータス: 進行中（生成ずみ／ユーザー確認まち）
- 参照: DESIGN.md §1（マチネ）/ §6.1（開幕）。実装は `app/scripts/gen-icons.mjs`（本番アイコンの正）
- 依存: なし。**35（製品版申請）より先に決めること**（アイコンはビルド入力なので、35 で作る production ビルドに載せる）
- 由来: クローズドテストの声（2026-09-12「アイコンが山に見える」。ほほ笑みラボの生徒さん）

## 目的

アイコンが劇場の舞台ではなく**山の稜線**に見える、という声。色と中央のスポット光は問題ないので、
**形だけ**直す。

## 何が山に見えていたか

1. **房飾りの弧が上向きの角（つの）を作っていた**：弧を5つ並べていたので、弧と弧のあいだに
   上向きの尖りができ、それが山の頂に読めた
2. **左右の幕が裾に向かって大きく外へ開いていた**（`panelInnerEdge` が `0.34 → 0.10`）：
   その斜めの輪郭が山の斜面になった
3. **幕の面がのっぺりしていた**：縦のひだが ±7% の淡い濃淡しかなく、布ではなく「塗られた斜面」に見えた
4. 結果、中央の空グラデが「山あいの空」、下の木の床が「地面」として読めてしまった

## 直したこと（色・光・構図の要素はそのまま）

- **房飾りの下端をほぼ水平に**（波の振幅 0.075 → 0.018）。上向きの角を作らない
- **左右の幕をほぼ垂直に吊るす**（`0.2 + 0.04·y²`。裾だけわずかに外へ広がる）。
  幕は「吊るされて垂れているもの」なので、縦に落ちる輪郭のほうが幕らしい
- **縦のひだをはっきり付ける**（±7% → ±16%）。布に見えれば斜面には見えない
- **房飾りを少し明るく**（×1.12）して、左右の幕と地続きに見せない
- **内側の縁を金線に**（淡い桜色 → `#E3AD4E`）。アプリ内の緞帳（チケット29）と同じ
  `curtain-gold` で、劇場の緞帳だと一目で分かる印にする。桜色は地に溶けて輪郭を作れていなかった
- 開口部を広げた（幕の占有が減り、舞台と床・スポット光が見えるようになった）

## メモ

### ビルドとの関係

アイコンは**ネイティブのビルド入力**なので、Play のアプリに反映するには新しいビルドが要る。
このアプリには OTA 更新（expo-updates）が無く、**29〜36 の修正も新しいビルドでしか届かない**ため、
どのみち 35 で production ビルドを1回作る。アイコン変更はそれに載せれば追加のビルドは要らない。
Play Console 側の掲載アイコン（512×512）とフィーチャーグラフィックはビルド不要で差し替えられる。

### PWA 側

`public/icons/*` も同じスクリプトが作るので、push すれば書き手Web（PWA）のアイコンは
ビルドなしで新しくなる。ホーム画面に追加ずみの端末は、追加し直すまで古いアイコンのままになる。
