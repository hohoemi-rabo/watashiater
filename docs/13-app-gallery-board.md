## メモ

### 座標系の契約（チケット14・17・21 が従う。正は `app/lib/board-layout.ts` 冒頭コメント）

- 単位はすべて「ボード幅=1」の正規化値（y も幅基準。1.0 を超えうる）。x, y は**ポラロイド外形（回転前）の中心**・rotation は度（時計回り）・z は整数（大きいほど手前）
- `photos.board_x/y/rotation/z` はこの単位で保存する。**board_x と board_y が両方 non-null のときだけ保存配置を採用**（チケット14は4項目セットで書き、「もとにもどす」で4項目 null に戻す）。rotation / z の欠落は自動値で補う
- 自動配置：created_at 昇順（**同時刻は id 昇順**。全順序でないと決定性が壊れる）で2列千鳥スロット、写真ごとの傾き・ジッターは `fnv1a(photo.id) ^ board_seed` の mulberry32 から引く（引き順 x→y→rot も契約）
- 安定性：追加は末尾に付くだけで既存写真は動かない／削除は後続スロットが詰まる／ドラッグ保存済みの写真もスロットの席は予約したまま（1枚保存しても他は動かない）

### 設計判断

- 木目は「軽量テクスチャ画像1枚」方式（`app/scripts/gen-wood-tile.mjs` で生成、依存なし・再現可能）。コード描画の縦線では木に見えなかった（実機フィードバック）。木目は ScrollView コンテンツ側に敷き **写真と一緒にスクロール**させる（RN Image の resizeMode="repeat"）
- **「机の縁」（外周の内側シャドウ・木枠）は削除**：§5 どおり実装→2回の増強（半透明影→8dp木枠→14dp木枠）でも「枠が何か分からない」ため、2026-08-12 のユーザー判断で撤去。**DESIGN §5 を同日更新済み**（チケット21の閲覧Webでも作らない）
- 重なり順は「z 昇順に並べ替えて描画順」で表現（zIndex・elevation 差は使わない。Android は同 elevation なら描画順が安定に効く）
- キャプションは既存の ZenMaruGothic_700Bold の 14px（`fontSizes.polaroidCaption` 追加。新ウェイトは読み込まない）
- 音声バッジは表示のみ（タップ再生はチケット15。バッジ用に recordings は answer_id の有無だけ引く）

### 検証結果

- tsc / lint / expo export クリーン。レイアウト関数は node で数値検証（決定性・左右上下の収まり・±3°・1枚目の配置が枚数に依存しないこと）
- 実機（Expo Go・2026-08-12）：配置・キャプション・バッジ・スクロールすべて OK（ユーザー確認済み）。木目はテクスチャ化・縁は削除で確定

### チケット14への申し送り

- ドラッグ保存は board_x/y/rotation/z の**4項目セット**で書く（座標系は上記契約）。最前面に出すときは「現在の最大 z + 1」
- 「もとにもどす」は subject の全写真の board_* を null に戻すだけで自動整列に復帰する
- ドラッグ対象の shadow-lifted 化はポラロイドの外側ラッパーで（`board-polaroid.tsx` は positional な props のみで memo 済み）
