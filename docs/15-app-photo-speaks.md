## メモ

### 設計判断（詳細は `app/components/photo-lightbox.tsx` 冒頭コメント）

- **タップ配線は Pressable**（`draggable-polaroid.tsx` の Animated.View と BoardPolaroid の間）。チケット14申し送りの2案のうち、閲覧モードでは Pan が disabled でそもそも競合しないため最小差分の Pressable を採用。ならべかえ中は `disabled={rearrange}` でタップ不活性（長押しつまみは Pan 活性化時の RNGH タッチ取消で従来どおり勝つ）
- **拡大表示は画面内オーバーレイ**（`photo-lightbox.tsx`。curtain-overlay と同じ absoluteFill + zIndex:10 の兄弟 View。Modal・モーダルルートは導入しない）。背景は `DIMMED_SKY = '#95C4D9'`（skyTop 85% + stageNavy 15% の混色。PAPER_TINT と同じトークン由来混色方式なので tokens.ts には足さない）
- **閉じる＝即アンマウント**（退場アニメなし）。CSS アニメに完了コールバックが無い＋「閉じたら音声が即止まる」が完了条件そのもの。`useAudioPlayer` はアンマウントで自動 release。「別写真タップの割り込み」はオーバーレイが盤面を覆うため構造的に発生しない（閉じる→開き直しで必ず前のプレイヤーが破棄される）
- **録音URLはボードの署名URL一括バッチに同梱**（`use-board-photos.ts`。worker は同一 subject なら写真＋録音の混在キーを受け付ける）。タップ→声が出るまでに worker 往復の無音を挟まない。鮮度はフォーカス毎 refetch が実質保証。`duration_sec` は UI に長さ表示が無いので取らない
- **録音がある写真に本文テキストは併記しない**（仕様の文字どおり「拡大＋音声」。2026-08-12 ユーザー決定）。録音なし＆本文空（声だけ消した等）の写真は「拡大＋キャプション＋とじる」のみ
- **音声読み込み失敗は10秒タイムアウトで検知**（SDK 54 の AudioStatus に error フィールドが無いため）。「もういちどよみこむ」→ 親 refetch → 新署名URLが props で流れ込み source 差し替え。読み込みが初めて成功した時点で1回だけ自動再生（リトライ成功後も含む＝聞きたくて押している）
- **audio mode は自動再生の直前に設定**（`playsInSilentMode` 等。設定しないと受話口から小さく鳴る＝チケット10の教訓）。録音モードに入れないので recording-box と違い後始末は不要
- Android 戻るは `usePreventRemove(lightboxItem !== null)` で1回目＝ライトボックスを閉じるだけ、2回目＝画面を出る

### 検証結果

- tsc / lint / expo export（Android バンドル）クリーン
- 実機（Expo Go）：未実施。確認項目は以下
  1. 声つき写真タップ → 拡大＋自動で声（スピーカーから。受話口でない）
  2. 一時停止／つづきを聞く／もういちど聞く。最後まで再生すると「もういちど聞く」だけになる
  3. 再生中に「とじる」・背面タップ・Android 戻る → 即座に音が止まる。戻る1回目はライトボックスのみ・2回目で画面を出る
  4. 声なし写真 → 拡大＋テキスト（長文スクロール）。声も文も無い写真 → 写真＋とじるのみ
  5. ならべかえモード：タップ無反応・長押しドラッグ従来どおり
  6. reduced-motion ON → アニメなしで開閉
  7. 機内モードで声つき写真 → 約10秒でエラー文言 → 電波復帰 →「もういちどよみこむ」で再生
