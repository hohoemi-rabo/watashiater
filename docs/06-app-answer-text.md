## メモ

### 保存のセマンティクス

- 既存回答あり → id で UPDATE／なし → INSERT。**upsert は使わない**
  （自由お題の1枠制約が部分 unique インデックスのため onConflict を指定できない）
- **本文を空にして保存 → 行を DELETE**（済スタンプ・進捗が戻る。空の「済」を作らない）。
  ただし削除前に photos / recordings の件数を確認し、**付属物があれば行を残して本文だけ空にする**
  （チケット09/10 以降の CASCADE 巻き添え削除を防ぐ。件数確認に失敗したときも消さない側に倒す）
- 保存成功の判定・遷移は保存処理の**戻り値**で行う（チケット04の教訓を適用）
- 保存ボタンの活性：新規は本文必須（自由お題はタイトルも）。既存があれば空でも保存可（＝削除）

### UI

- 書きかけ保護：`usePreventRemove`（@react-navigation/core）で未保存の変更があるときだけ
  「もどる」（ハードウェアバック含む）を差し止め、確認ダイアログ
- 保存成功スタンプ：spot-yellow の円形ボーダー「ほぞん しました」が scale 1.6→1.0 で
  ポンと押される（Reanimated の CSS 風 keyframes・250ms）→ 950ms 後に自動で戻る。
  `useReducedMotion` 時はアニメなし表示。戻りタイマーは unmount で解除（二重 back 防止）
- 音声切替は左「じぶんで かく」（stageNavy 塗り・選択中）／右「こえで はなす」
  （無効・「じゅんびちゅう」表示）。curtain-red は保存ボタン専用
- ポラロイド空枠：白フチ 左右上8px・下28px（DESIGN §5）・-2° 傾き・内側は破線枠に
  「ここに 写真が のります」
- プレフィルは読み込み完了時に一度だけ（編集中に refetch が来ても入力を上書きしない）
- お題の読み込み失敗はリトライ画面、不正な promptId は「見つかりませんでした」

### 実機フィードバックによる調整（コミット c92ad41 ほか）

1. モード切替ラベルの左右余白を拡大
2. 本文入力の lineHeight 指定を撤去：**Android はカーソルを行の高さいっぱいに描く**ため、
   行間1.7倍だとカーソルだけ大きく見える。読み物の行間1.7は表示側でのみ使う
3. **保存ボタンをスクロール外の固定フッターへ**：adjustResize でキーボードの真上に浮き、
   キーボードを閉じずに1タップで保存できる。以後、入力を伴う画面はこの形を踏襲する
4. **UI 文言の表記方針**：「じぶんで かく」→「自分でかく」「こえで はなす」→「声で話す」
   （ユーザー指示）。ひらがな分かち書きにしすぎず日常漢字を使う。以後の画面もこの方針
   （REQUIREMENTS の固定文言はそのまま）
