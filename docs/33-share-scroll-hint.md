## 目的

みんなに見せる画面は4枚のカード（招待コード・見せる用リンク・家族・見たよ）が縦に並び、1画面に収まらない。下に続きがあることに気づかない生徒さんがいた。画面下に「下にもあります」のしるしを浮かべ、スクロールし始めたら消す。

## 決定事項（2026-09-08 ユーザー確認済み）

- **画面下端に浮く「下にもあります ▼」**：半透明の白い錠剤型（card-white・shadow-raised）に文字と ChevronDown アイコン。押すと1画面分スクロールする
- **少しスクロールしたら消える**（40px 目安）。内容が画面に収まっているときは最初から出さない
- 動きは出現時の 200ms フェードのみ。矢印を揺らし続けない（DESIGN §8）
- 今回置くのは「みんなに見せる」だけ。部品は再利用できる形にし、お題一覧・設定など他の長い画面に置くかは別途判断

## 実装方針

- `components/scroll-hint.tsx`：`useScrollHint()`（ScrollView に渡す `onScroll` / `onContentSizeChange` / `onLayout` と `visible` を返す）＋ `ScrollHint`（表示部品。`bottom` はセーフエリア＋余白）。ScrollView 自体は各画面が持ち続ける（ラッパー部品にしない＝既存画面の構造を変えない）
- 表示判定は「内容の高さ > 表示領域＋8px」かつ「scrollY < 40」。判定に必要な値は state ではなく ref に持ち、再レンダーを増やさない
