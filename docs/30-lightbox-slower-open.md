# 30. ギャラリーの拡大表示：開く動きをゆっくりに

## 目的

「幕が中央から左右へ広がり、その前で写真が上映される」演出は 320ms では速すぎて動きが読めない。約2倍にして「広がった」と分かる速さにする。

## 決定事項

- 幕の広がり `CURTAIN_SPREAD_MS`：320 → **640ms**
- 写真が現れるまでの待ち `CONTENT_DELAY_MS`：140 → **300ms**（幕が8割ほど開いたところ、という比率は維持）
- 写真の立ち上がり `CONTENT_RISE_MS`：200 → **320ms**
- 閉じる＝即アンマウントは変えない（「閉じたら音声が即止まる」が完了条件。docs/15）
- 閲覧Web の拡大表示（`web/components/photo-lightbox.tsx`）は今回対象外。同じ体験にしたくなったら別チケットで CSS の duration を合わせる
