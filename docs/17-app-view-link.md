## メモ

### 設計判断

- **ドメインは暫定**：`EXPO_PUBLIC_WEB_URL=https://watashiater.vercel.app`（app/.env。2026-08-12 ユーザー決定）。**チケット20の Vercel デプロイで実ドメインに確定させ、.env と本メモを更新すること**（worker URL と同じ「デプロイ時に確定」方式）
- **スラッグ**は小文字 base32 風 32文字×16桁（80bit）。`lib/view-link.ts`。リンクは手入力しないので紛らわしい文字の除外はせず、256%32=0 で剰余の偏りなし
- **再発行は「止める → つくり直す」の2段階**（有効リンクは partial unique で subject につき1本。新規 INSERT の 23505 がスラッグ衝突と区別できないため、必ず無効化してから作る規約）。UI もこの2段階が最小
- **無効化は worker に即座に効く**（slug 照会が `is_active=is.true`。チケット08実装・テスト済み＝worker 変更なし）。ただし**既発行の署名付きメディア URL は最長1時間生き残る**（docs/08 の受容済み設計）
- 注意文「このリンクを知っている人は だれでも 見られます。」は発行前・発行後ともカードに常時表示（発行の瞬間だけでは見落とすため）
- ボーイスカウト修正：`lib/invite.ts` の `CODE_ALPHABET` が31文字なのに「256%32=0」とコメントしていた誤りを修正（大文字 L を戻して32文字に。発行済みコードへの影響なし）
