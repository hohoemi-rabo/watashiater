# 31. 回答画面：写真の枠をタップしても写真を選べるように

- ステータス: 未着手
- 参照: REQUIREMENTS.md §3.2（写真添付）/ DESIGN.md §7 回答画面（「写真添付枠はポラロイド型の空枠」。本チケットで改訂）/ §5 質感。実装は `app/components/photo-strip.tsx`（呼び出し元 `app/app/answer/[promptId].tsx` の `onAdd` をそのまま使う）
- 依存: なし
- 由来: クローズドテストの声（2026-09-08 ユーザー依頼「写真を載せるとき、ボタン以外に写真のところをタップする機能」）

## 目的

今は「写真をのせる」ボタンだけが入り口で、写真が0枚のときに出る点線の空枠は押せない。生徒さんは枠を押そうとする。枠を押せる入り口にし、写真があるときも枠を出し続けて「ここに次の写真がのる」を形で示す。

## 決定事項（2026-09-08 ユーザー確認済み）

- **空枠を常に出し、タップで追加**：写真の末尾に「＋ 写真をのせる」の点線ポラロイド枠を出し続ける。5枚に達したら消す
- 既存の写真はタップしても何も起きない（今と同じ。拡大表示はギャラリーの役目）
- 「写真をのせる」ボタンも残す（入り口は2つ。ボタンに慣れた人を迷わせない）
- 枠が押せないとき（読み込み中・アップロード中・オフライン）は押せない見た目にし、オフラインは今までどおり案内文を出す
