# 34. 文言の見直し：ひらがなを減らし、日常の漢字で書く（「お題を書く」を含む）

## 目的

ひらがなの分かち書き（例：「しゃしんを のせる」「よみこめませんでした」）は、60〜80代にはかえって読みにくい。日常的な漢字をスペースなしで使い、短い文にする。REQUIREMENTS 由来の固定文言も含めて、アプリ・閲覧Web・ストア掲載文の表記を揃える。

## 決定事項（2026-09-08 ユーザー確認済み）

- ホームの「つづきをかく」→ **「お題を書く」**
- 固定文言は3つとも漢字にする：**「じぶん史をつくる」→「自分史を作る」／「みたよ」→「見たよ」／「ならべかえ」→「並べ替え」**（REQUIREMENTS §3・§4.1 の記述も更新。コードの識別子・ルート名・DB の値は変えない）
- 表記ルール（DESIGN §10 に書き込む）：
  - 日常的な漢字はスペースなしで使う：写真・家族・声・思い出・答える・書く・読み込む・作る・送る・見る・設定・保存・準備中・確かめる など
  - 語と語の間のスペース（分かち書き）は廃止。区切りは読点「、」と短い文で
  - 送り仮名は標準表記（「答える」「作る」「読み込む」）
  - 外来語・専門語を避ける原則は維持（アップロード→のせる、生成→作る。REQUIREMENTS §4.1）
  - 丁寧体（〜ください／〜できます／〜しましょう）は維持。命令調にしない
  - 難しい漢字は避ける（例：「失効」→「使えなくなる」、「認証」→「ログイン」）
- お題の文言（DB の prompts）は既に漢字表記なので変更なし
